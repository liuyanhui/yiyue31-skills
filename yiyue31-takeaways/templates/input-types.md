# 输入类型分类

## 内容领域维度

| 类型代码 | 名称 | 描述 | 典型特征 |
|---------|------|------|---------|
| TECH | 技术文章 | 涉及编程、架构、技术方案等 | 包含代码、技术术语、架构图 |
| MGMT | 管理心得 | 团队管理、项目管理经验 | 讨论流程、沟通、决策 |
| ACAD | 学术论文 | 研究论文、学术文章 | 有摘要、方法论、实验数据 |
| POPU | 科普文章 | 面向大众的科学普及 | 语言通俗、举例生动 |
| PROD | 产品文档 | 产品说明、用户手册 | 功能描述、操作步骤 |
| BIZN | 商业分析 | 行业分析、市场研究 | 数据图表、趋势分析 |

## 文章结构维度

| 类型代码 | 名称 | 描述 | 典型结构 |
|---------|------|------|---------|
| TUTOR | 教程类 | 循序渐进的教学 | 步骤1→步骤2→步骤3 |
| CASE | 案例分析 | 通过实例讲解 | 背景→问题→方案→结果 |
| THEORY | 理论研究 | 深入探讨理论 | 概念→原理→证明 |
| EXP | 经验分享 | 个人/团队经验总结 | 背景→经历→教训 |
| REVIEW | 综述类 | 综合性总结概述 | 多角度汇总 |
| GUIDE | 指南类 | 操作性指导 | 准备→执行→检查 |

## 组合编码规则

输入类型 = 内容领域代码 + "-" + 文章结构代码

示例：`TECH-TUTOR`（技术教程）、`MGMT-EXP`（管理经验分享）
