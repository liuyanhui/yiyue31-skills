# 对比评测型

**对应方法论**：对比分析法

**适用场景**：工具对比、方案选型、产品评测

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 对比目的 | 为什么要做这个对比 | 是 |
| 对比维度 | 选择的对比维度有哪些 | 是 |
| 候选方案 | 对比的对象有哪些 | 是 |
| 方案A | 在各维度上的表现 | 是 |
| 方案B | 在各维度上的表现 | 是 |
| ... | ... | 是 |
| 评分总结 | 各方案的得分情况 | 是 |
| 推荐结论 | 推荐哪个方案，为什么 | 是 |
| 决策建议 | 如何根据实际情况选择 | 是 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 对比目的
为什么要做这个对比

### 对比维度
选择的对比维度有哪些，为什么选这些维度

### 候选方案
对比的对象有哪些

### 方案A/B/...
在各个维度上的具体表现

### 评分总结
各方案的得分情况

### 推荐结论
推荐哪个方案，为什么

### 决策建议
如何根据实际情况选择
