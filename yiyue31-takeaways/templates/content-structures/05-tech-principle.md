# 技术原理型

**对应方法论**：2W1H（What→Why→How）

**适用场景**：技术解析、架构分析、知识讲解

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 是什么 | 这个技术/概念是什么 | 是 |
| 为什么 | 为什么需要它，解决了什么问题 | 是 |
| 怎么做 | 它的工作原理是什么 | 是 |
| 核心概念 | 关键概念和术语解释 | 是 |
| 架构/结构 | 系统架构或组成结构 | 是 |
| 与其他方案对比 | 与其他方案的比较 | 否 |
| 应用场景 | 适用的场景和限制 | 否 |
| 局限性 | 它的不足和边界 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 是什么
这个技术或概念的定义和基本介绍

### 为什么
为什么需要它，解决了什么问题

### 怎么做
它的工作原理是什么，如何运作

### 核心概念
关键概念和术语的详细解释

### 架构/结构
系统架构或组成结构

### 与其他方案对比
与其他方案的比较分析

### 应用场景
适用的场景和使用限制

### 局限性
它的不足之处和适用边界
