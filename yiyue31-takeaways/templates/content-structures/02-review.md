# 复盘总结型

**对应方法论**：PDCA循环（Plan→Do→Check→Act）

**适用场景**：项目复盘、工作总结、活动回顾

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 计划 | 当初的目标和计划是什么 | 是 |
| 执行 | 实际做了什么，关键数据和指标 | 是 |
| 检查 | 结果如何，哪些做得好，哪些不好 | 是 |
| 改进 | 下次如何做得更好，具体行动计划 | 是 |
| 附件 | 相关数据、图表 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 计划
回顾当初设定的目标和计划

### 执行
描述实际执行过程，包含关键数据和指标

### 检查
分析结果，哪些做得好，哪些不好

### 改进
下次如何做得更好，给出具体的行动计划

### 附件
相关数据、图表等支撑材料
