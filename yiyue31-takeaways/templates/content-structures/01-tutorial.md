# 教程入门型

**对应方法论**：金字塔原理（结论先行、以上统下、归类分组、逻辑递进）

**适用场景**：零基础入门、系统性学习路径

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 核心结论 | 一句话概括学完能达到什么水平 | 是 |
| 学习路线 | 按顺序排列的学习步骤 | 是 |
| 第一步 | 概念解释 + 实践操作 | 是 |
| 第二步 | 概念解释 + 实践操作 | 是 |
| ... | ... | 是 |
| 常见误区 | 新手易错点 | 否 |
| 进阶方向 | 学完后如何深入 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 核心结论
结论先行，让读者快速了解学习目标

### 学习路线
系统性规划学习路径，让读者有清晰的方向

### 步骤章节
每个步骤包含：
- 概念解释（是什么）
- 实践操作（怎么做）

### 常见误区
总结新手容易犯的错误，帮助避坑

### 进阶方向
学完后如何继续深入
