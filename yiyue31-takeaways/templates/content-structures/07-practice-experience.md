# 实战心得型

**对应方法论**：KJ法（收集信息→归类分组→明确核心→形成方案）

**适用场景**：个人实战经验、实战分享

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 场景 | 当时的实战场景是什么 | 是 |
| 做法一 | 具体做法1 | 是 |
| 做法二 | 具体做法2 | 是 |
| ... | ... | 是 |
| 效果 | 取得了什么效果 | 是 |
| 关键要点 | 提炼出来的关键要点 | 是 |
| 可复制经验 | 其他人可以如何借鉴 | 是 |
| 避坑指南 | 遇到的问题和解决方案 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 场景
当时的实战场景是什么

### 做法
具体做了什么，可以有多个做法

### 效果
取得了什么效果，有什么成果

### 关键要点
提炼出来的关键要点和核心经验

### 可复制经验
其他人可以如何借鉴

### 避坑指南
遇到的问题和解决方案
