# 趋势洞察型

**对应方法论**：U型思考（问→挖→破→立）

**适用场景**：趋势分析、行业洞察、战略判断

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 现象 | 观察到的现象或趋势是什么 | 是 |
| 演变 | 过去是如何发展到现在的 | 是 |
| 根本原因 | 背后的驱动因素是什么 | 是 |
| 未来趋势 | 未来会如何发展 | 是 |
| 机会窗口 | 有什么机会可以把握 | 是 |
| 潜在风险 | 有什么风险需要注意 | 是 |
| 我的判断 | 我的观点和结论 | 是 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 现象
观察到的现象或趋势是什么

### 演变
过去是如何发展到现在的

### 根本原因
背后的驱动因素是什么

### 未来趋势
未来会如何发展

### 机会窗口
有什么机会可以把握

### 潜在风险
有什么风险需要注意

### 我的判断
我的观点和结论
