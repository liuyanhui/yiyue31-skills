# 案例解析型

**对应方法论**：SCQA模型（Situation→Complication→Question→Answer）

**适用场景**：案例分析、问题复盘、经验学习

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 背景 | 当时的情境是什么 | 是 |
| 冲突 | 遇到了什么问题或挑战 | 是 |
| 问题 | 需要解决的核心问题是什么 | 是 |
| 答案 | 采取了什么方案 | 是 |
| 结果 | 方案的效果如何 | 是 |
| 可复制性 | 其他场景可以如何借鉴 | 是 |
| 我的启示 | 我从中学到了什么 | 是 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 背景
当时的情境是什么

### 冲突
遇到了什么问题或挑战

### 问题
需要解决的核心问题是什么

### 答案
采取了什么方案

### 结果
方案的效果如何

### 可复制性
其他场景可以如何借鉴，经验是否可迁移

### 我的启示
从中学到了什么，有什么收获
