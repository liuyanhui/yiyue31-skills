# 方法论型

**对应方法论**：黄金圈法则（Why→How→What）

**适用场景**：方法阐述、框架介绍、理念传递

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 为什么 | 这个方法论的核心理念和初衷 | 是 |
| 怎么做 | 核心原则和方法 | 是 |
| 是什么 | 具体的框架、工具、实践 | 是 |
| 核心原则 | 方法论的关键原则 | 是 |
| 实践步骤 | 如何实施这个方法论 | 是 |
| 适用场景 | 什么情况下使用 | 否 |
| 案例示例 | 实际应用案例 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 为什么
这个方法论的核心理念和初衷是什么

### 怎么做
核心原则和方法是什么

### 是什么
具体的框架、工具和实践

### 核心原则
方法论的关键原则有哪些

### 实践步骤
如何实施这个方法论

### 适用场景
什么情况下使用这个方法论

### 案例示例
实际应用案例
