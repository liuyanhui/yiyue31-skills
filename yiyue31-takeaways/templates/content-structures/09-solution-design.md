# 方案设计型

**对应方法论**：空雨伞笔记法（空→雨→伞）

**适用场景**：问题解决、方案设计、决策制定

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 空：现状/事实 | 客观描述当前情况，只记录事实 | 是 |
| 雨：分析/预测 | 基于事实的分析，解释为什么、会怎样 | 是 |
| 伞：行动方案 | 具体可执行的措施，明确怎么做 | 是 |
| 附件：备选方案 | 如果主方案不行的替代方案 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 空：现状/事实
客观描述当前情况，只记录事实，不掺杂主观判断

### 雨：分析/预测
基于事实进行分析，解释为什么、会怎样发展

### 伞：行动方案
具体可执行的措施，明确怎么做

### 附件：备选方案
如果主方案不行的替代方案
