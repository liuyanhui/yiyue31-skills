# 操作手册型

**对应方法论**：5W2H（Who/What/When/Where/Why/How/How much）

**适用场景**：实践指南、操作教程、SOP文档

## 章节结构

| 章节 | 内容要求 | 必填 |
|------|---------|------|
| **文章概述** | 背景、主体介绍、原文简介、我的关注点 | 原文简介、我的关注点必填 |
| 是什么 | 要操作的对象/任务是什么 | 是 |
| 为什么要做 | 为什么要做这个操作 | 是 |
| 谁来做 | 适用的人群和前置条件 | 是 |
| 何时做 | 适用场景和时机 | 是 |
| 在哪里做 | 环境、平台要求 | 是 |
| 怎么做 | Step by step 操作步骤 | 是 |
| 注意事项 | 常见错误和避坑指南 | 否 |
| FAQ | 常见问题解答 | 否 |

## 章节说明

### 文章概述
作为一个连贯的整体呈现，按照以下结构生成：
```
[背景/主体介绍（可选）]
[原文简介：讲了什么]
→ [我的关注点：基于原文，我关注的是什么]
（直接进入正文）
```

### 是什么
明确要操作的对象或任务

### 为什么要做
说明做这个操作的必要性和价值

### 谁来做
定义适用人群和前置条件

### 何时做
说明适用的场景和时机

### 在哪里做
说明所需的环境和平台要求

### 怎么做
详细的操作步骤，step by step

### 注意事项
常见错误和避坑指南

### FAQ
常见问题解答
