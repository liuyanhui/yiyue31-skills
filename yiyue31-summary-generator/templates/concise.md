# Summary Template: Concise（简洁笔记）

## Description
技术学习笔记模板，适合工程师或学生快速复习。将复杂技术文章转化为易懂、结构化的笔记。默认中文，用户可指定使用英文。

## Structure

```markdown
# 技术学习笔记：[Original Title]

**来源**: [URL or file path]

**作者**: [if available]

**模板**: Concise（简洁笔记）

---

**文章标题**：[Original Title]

**概述**：[1-2句概述：核心主题、目的和关键贡献]
```

## Guidelines

- **格式**: Markdown格式（标题用##，列表用-或数字，代码用```）
- **语言**: 默认中文，用户可指定英文
- **信息来源**: 只用文章提供的信息，不添加外部知识
- **专有名词**: 保留英文原名，如 AI Agent, ZooKeeper, prompt 等
- **代码/图表**: 用伪代码或简述表示
- **输出**: 直接是笔记，无额外解释

## Best For

- 技术文章学习笔记
- 工程师快速复习
- 学生学习整理
- 技术知识沉淀
