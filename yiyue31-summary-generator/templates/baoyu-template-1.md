# Summary Template: Baoyu Learning Notes

## Description
技术学习笔记模板，适合工程师或学生快速复习。将复杂技术文章转化为易懂、结构化的中文笔记。

## Guidelines

- **总长度**: 800-1500字，优先简洁
- **格式**: Markdown格式（标题用##，列表用-或数字，代码用```）
- **语言**: 中文
- **信息来源**: 只用文章提供的信息，不添加外部知识
- **专有名词**: 保留英文原名，如 AI Agent, ZooKeeper, prompt 等
- **代码/图表**: 用伪代码或简述表示
- **输出**: 直接是笔记，无额外解释

## Best For

- 技术文章学习笔记
- 工程师快速复习
- 学生学习整理
- 技术知识沉淀
