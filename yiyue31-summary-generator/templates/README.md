# Tech Article Summary Templates

This directory contains summary templates for the `yiyue31-summary-generator` skill. All templates are designed specifically for technical articles.

## Available Templates

| Template | Description | Best For |
|----------|-------------|----------|
| `standard.md` | Balanced general-purpose template (English) | Most technical articles, blog posts, announcements |
| `baoyu-template-1.md` | 技术学习笔记模板（中文） | 技术文章学习笔记、工程师快速复习 |
| `baoyu-template-2.md` | 技术学习笔记模板增强版（中文） | 深度学习、按文章顺序分节整理、突出创新点 |

## Adding New Templates

To add a new template:

1. Create a new `.md` file in this directory
2. Use the following structure:

```markdown
# Summary Template: [Template Name]

## Description
[One-line description of when to use this template]

## Structure

```markdown
# [Your Title Format]

**Source**: [URL or file path]
[Additional metadata fields as needed]

---

## [Section 1]
[Content guidelines]

## [Section 2]
[Content guidelines]
```

## Guidelines

- [Guideline 1]
- [Guideline 2]

## Best For

- [Use case 1]
- [Use case 2]
```

3. Update the table above in this README.md

## Removing Templates

To remove a template:
1. Delete the `.md` file from this directory
2. Update the table above in this README.md
