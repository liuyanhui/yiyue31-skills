# Tech Article Summary Template: 技术文章总结模板

## Description

论文笔记模板，适合论文的总结，帮助读者快速学习和理解论文。按文章顺序分节整理，突出创新点和实用价值。默认中文，用户可指定使用英文。

## Template Content

```markdown

# 原标题：{{Original Title}}

**来源**: {{URL or file path}}

**作者**: {{if available}}

**模板**: {{当前模板名称或模板的文件名}}

**字数**：{{xxx}}字

---

# {{文章/论文标题}} 阅读总结

## 基本信息
- **原文链接**：{{URL}}
- **作者/来源**：{{作者名、会议或期刊名}}
- **阅读时间**：{{日期}}
- **关键词**：{{3~5个关键词}}

## 核心问题
{{文章试图解决什么问题？背景是什么？}}

## 主要观点/结论
{{用 2~3 句话概括作者的核心结论。}}

## 技术要点
1. **关键技术**：{{方法、架构、算法等}}
2. **创新点**：{{与现有工作的差异}}
3. **实验/验证**：{{如何证明效果？数据或案例}}

## 我的思考
- **启发**：{{对当前工作的启发}}
- **疑问**：{{文中未解释清楚或有争议的地方}}
- **延伸**：{{可进一步探索的方向}}

## 行动项（可选）
{{如果有下一步计划，列出。}}
```

## Rules

- **格式**: 使用bullet points和层级缩进，便于阅读和复习
- **结构**: 按文章顺序分节（引言、背景、方法、实现、结论等）
- **语言**: 默认中文，保留英文专有名词（如 AI Agent, prompt 等）
- **准确性**: 保留技术准确性，用易懂语言解释复杂概念
- **信息来源**: 只基于提供的文章内容，不添加外部知识
- **字数要求**：不能超过原文字数。
