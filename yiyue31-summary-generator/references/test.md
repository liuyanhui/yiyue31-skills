# Test Article

This is a sample article for testing the word counter utility.

## Introduction

The word counter can count words, characters, lines, and paragraphs in text files. It supports various file formats including markdown and plain text files.

## Features

- Count words accurately
- Count characters with or without spaces
- Count lines and paragraphs
- Support for multiple file formats
- Easy to use CLI interface

## Technical Details

This utility is written in TypeScript and provides type-safe functions for text analysis. It can be used as a command-line tool or imported as a module in other TypeScript projects.

## Conclusion

The word counter is a simple yet powerful utility for text analysis. It's perfect for writers, editors, and developers who need to analyze text files quickly and accurately.
