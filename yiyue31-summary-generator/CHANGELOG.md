# Changelog

All notable changes to the yiyue31-summary-generator skill will be documented in this file.

## [1.1.0] - 2025-03-06

### Added
- Language selection workflow (Chinese/English)
- Quality validation checklist
- User feedback loop mechanism
- Template metadata with validation rules
- README.md with comprehensive documentation
- TEST_PLAN.md with 12 test cases
- CHANGELOG.md for tracking changes

### Changed
- Fixed skill name from `yiyue31-tech-article-summarizer` to `yiyue31-summary-generator`
- Enhanced description to include Chinese keywords
- Improved template selection workflow with language preference
- Updated all templates with YAML frontmatter metadata

### Improved
- Template metadata now includes:
  - Target length and reading time
  - Section specifications
  - Feature flags
  - Version tracking

- Quality standards now include:
  - Validation checklist
  - User feedback mechanism
  - Length guidelines per template

- Documentation improvements:
  - Comprehensive README with examples
  - Detailed test plan covering all scenarios
  - Clear workflow descriptions

## [1.0.0] - Initial Release

### Features
- Three summary templates: Standard, Concise, Comprehensive
- Support for multiple input types (URL, file, paste)
- Article type detection
- Bilingual support (Chinese default, English available)
- Article-specific summary adaptation
- Quality standards and guidelines
