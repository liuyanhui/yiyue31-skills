## 三、各方独有重要发现

**翻译家**：R5 全流程无文风基准/试译锚点（"八个人译的书"的病因侧缺口）；R7 阶段B 缺裁定台账（直注兜底扫描不可判定）；R8 冷读者接力无重叠无台账（接缝恰是高发区）；R9 换模型重翻破坏邻接连贯（重翻 prompt 未附邻 chunk 中文）；R10 Step 2 主 agent 全文阅读违背自家 O(1)（500KB 时破功）；R11 PM 20% 选样未脚本化（挑软柿子回归）。核心忠告：**赌注全押检测端、生成端语境裸奔是方法论倒挂**——检测只能发现不能复原"一个人的声音"。

**架构师**：风险1 探针注入路径未定义（谁保证样本进审校流？靠自觉=违反零信任；建议 status 队列注入+缺报告即 FAIL）；风险3 原文变更 re-keying 未定义（应按内容 sha 匹配而非序号）；风险4 M1 单会话不可达成（建议拆 M1a segment+verify-mech / M1b status / M1c final-gate+probe）；缺陷4 新鲜度豁免清单要精确到 glob（REPORT.md 晚于终检会被误判 stale）；缺陷7 "≥8 chunk"预估是旧粒度遗留死条件；缺陷8 附录 A 残留（抽样/轮上限 2 vs 3）。**可简化项**：audit.mjs 推迟 M5、N>1 并发实现推迟 v2（只留参数位）、探针每维度每 run 1 个即止、terms.md 周期合并推迟、分段调参降为两遍启发式、PENDING-USER 只做标记文件。

**用户**：介入点走查表显示 happy path 无问句，但**介入集中在时间轴**——会话接力"每段一推"（500KB≈十几次）、限流无退避重试（一晚上推好几次）、中断恢复扳机仍是我开口；三件主动出手的事两件没入口（用户触发的重翻某章、干净中止/封存）；缺进度可视入口（"现在到哪了还剩多久"）；REPORT 缺首屏人话结论、交付摘要未内联到聊天输出；小文档应自动交接而非让我重发；对账表应记"用户开口次数"。核心忠告：**"零介入"的验收标准应从"流程里没有问句"改成"离开 12 小时后回来的体验"**。

## 四、修订清单（建议 DESIGN v2）

### P0 开工前必修（对应架构师"M1 前必修"，三方裁决缝合）

1. **重排收尾顺序，给冷读者牙齿**（X1）：统稿 → 冷读者（含 PM 通读）→ 发现分流修复（错误走修复闭环；文风走定点修+接缝复查）→ pm-review → **终检（真正最后一步）** → PASS 原子改名 → REPORT 定稿。新鲜度豁免清单同步更新（REPORT/pm-review 明确豁免或改序）。
2. **修 §5 目录**（X2）：四份独立 evaluate prompt + 冷读者 prompt + 元信息模板落位，删合并残根；同步清洗附录 A 残留（抽样字样、轮上限 2→3）。
3. **冻结"译文变更分类 → stale 规则"**（X3）：修复类=相关维度重审；统稿机械替换类=diff 清单+consistency 重扫代替四维重审+REPORT 披露；句式级统稿改写仍走重审；统稿轮 ≤2 终止。
4. **定待决清单终态**（X4）：待决项自动转 PENDING-USER 挂起（推荐，符合零介入例外）或 PASS-with-disclosure——需 Yiyue 拍板；统一术语。
5. **写死探针注入机制**：status 队列注入伪审校单元 + 探针缺报告即终检 FAIL + 源侧 ground truth + 每维度每 run ≥1；写明威胁模型边界（防偷懒不防对抗）。
6. **交接包规格 + 术语投影**（X5）：五件套（chunk 地图/前 chunk 遗留摘要/既定译法投影/修辞叙事台账/文风基准卡）+ per-chunk glossary 投影 + 串行模式追加邻 chunk 真实中文末段（sha 绑定，N>1 退回纯预生成）。
7. **枚举新鲜度产物集合/豁免清单**：精确到 glob，统一"mtime=软判 / sha+重执行=硬判"口径（连 REQUIREMENTS 验收 #2 的 mtime 表述一起修）。

### P1 质量增强（翻译家主线，M2 前落）

8. 文风基准卡 + chunk 1 过审后节选锚点例文入交接包（R5）
9. 审校单元减半（chunk 切两半送审，覆盖不减）+ prompt 分节报告结构 + 阈值随输入缩放 + 审校输入补 glossary/brief（R4）
10. 阶段B 裁定台账（«» 逐条裁定记录，直注兜底可判定）（R7）
11. 冷读者接力段间重叠 ~2KB + 递进台账 + 收尾专读接缝（R8）；升级重翻必附邻 chunk 中文首末段 + 接缝复查（R9）
12. Step 2 大文档改 subagent 分段提取 + 脚本合并（R10）；PM 选样脚本化分层（R11）

### P2 体验补齐（用户主线，M2 落）

13. 用户动词表：`继续/停止（封存）/重翻第 N 章/进度？`——全部挂 resume oracle；小文档自动交接
14. 进度可视：status 人话一行（X/Y、阶段、已耗时、剩余预估、下次该说的话）
15. REPORT 首屏人话结论 + 交付摘要内联到聊天输出 + 对账加"用户开口次数"
16. 限流自动退避重试（指数退避，超限转挂起）——不让限流夜变成用户的推杆夜

### 简化裁决（架构师建议，需 Yiyue 认可）

17. audit.mjs 推迟 M5；**N>1 并发实现推迟 v2（只留参数位）**；terms.md 周期合并推迟；分段调参两遍启发式；PENDING-USER 极简标记文件
18. 里程碑重切：M1a（segment+verify-mech，立即可开）→ M1b（status，需 P0-3/4 冻结）→ M1c（final-gate+probe，依赖 M1b）；"溢出恢复"验收移 M3/M4
