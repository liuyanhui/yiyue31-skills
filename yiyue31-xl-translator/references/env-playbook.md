# 环境处置手册（env-playbook）— 横切细则

> SKILL.md 横切机制只留一行引用；API 限流/流停滞/并发/退避/溢出恢复细则在本件（§6.1 #6 迁出）。

## D1 环境处置模板（编排侧）

- 429 `[1302]`（突发限流）→ 等在途单元回传一个后原样补派（并发已降即自愈）。
- 429 `[1308]`（五小时配额上限）→ **定时等窗续跑**（cron 定在重置时刻后 ~5min；不空转重试；cron 属宿主调度层，见 improvement-proposal §10）。
- 流停滞（watchdog 600s）→ **先核验无半成品落盘**（读报告文件头 sha 是否旧值）→ 原样重派；禁 web 条款随派发提示词附带。
- 并发纪律：**≤5 两波制**（首波 5 + 回传 1-2 后派次波 3-4；8 并发实测触发突发限流）。

## 限流四层保证

1. 宿主退避吸收瞬时限流；
2. 单元派发失败指数退避重试 ≤2 次 → 仍败干净挂起（status.md 记原因 + 续跑口令）；
3. 逐 chunk 流水完成即落盘带 sha → 任意时刻中断损失 ≤1 在途单元；
4. 幂等续跑（sha 命中即跳过）。被动触发无常驻能力，不承诺自动唤醒。
