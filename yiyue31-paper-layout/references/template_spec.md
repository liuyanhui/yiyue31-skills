# 中文期刊论文模板格式规范

> Last updated: 2026-04-29 19:10:00

> 从 `论文模板221123.docx`（西北工业大学学报模板）提取的完整格式规范。
> 适用于大多数中文科技期刊，可根据目标期刊微调。

---

## 一、页面设置

### 纸张与边距

| 项目 | 首页（标题区） | 正文区 | 参考文献/英文区 |
|------|--------------|--------|----------------|
| 纸张 | A4 (21.00 × 29.70 cm) | 同左 | 同左 |
| 上边距 | 2.15 cm | 4.00 cm | 2.15 cm |
| 下边距 | 2.15 cm | 2.15 cm | 2.15 cm |
| 左边距 | 1.95 cm | 1.95 cm | 1.95 cm |
| 右边距 | 1.95 cm | 1.95 cm | 1.95 cm |
| 栏数 | 单栏 | **双栏**（间距 422 DXA ≈ 0.74 cm） | 单栏 |
| 页眉距离 | 1.37 cm | 1.35 cm | 1.35 cm |
| 页脚距离 | 1.27 cm | 1.27 cm | 1.27 cm |

### 分节说明

文档分为 4 个 Section：
- **Section 1**：首页标题区（单栏），包含中英文标题、作者、摘要等
- **Section 2**：正文区（双栏），正文上边距加大到 4.00 cm
- **Section 3**：参考文献区（单栏）
- **Section 4**：文末引用格式等（单栏）

## 三、页眉页脚

### 首页页眉

```
####年  ## 月                             西 北 工 业 大 学 学 报    ##(Month)  ####(Year)
第##卷  第##期                    Journal of Northwestern Polytechnical University                    Vol.##   No.##
```

> 两行，第一行中文期刊名 + 英文日期，第二行卷期号 + 英文期刊名 + 英文卷期号。

### 正文页页眉

```
第##期    作者，等：文章题目    ###（页码）
```

> 使用 Tab 制表符分隔三段：期号、作者题目、页码。

### 页脚

居中显示页码（使用域代码自动生成）。

## 四、段落格式细节

### 行距

- 全文使用**单倍行距**（`SINGLE`）
- docx-js 中设置：`spacing: { line: 276 }`（对应固定值约 13.8pt）

### 段前段后间距

| 元素 | 段前 | 段后 |
|------|------|------|
| 论文标题 | 198755 DXA (≈3.5pt) | 198755 DXA |
| 一级标题 | 160 DXA | 80 DXA |
| 二级标题 | 120 DXA | 60 DXA |
| 正文 | 0 | 0 |
| 图题 | 76200 DXA (≈1.3pt) | 38100 DXA |
| 参考文献标题 | 较大间距 | 100 DXA |

### 摘要区缩进

- 中文摘要、关键词、中图分类号等段落：**左右各缩进 2 字符**
- 英文 Abstract、Key words：**左右各缩进约 0.74cm**

### 首行缩进

- 正文段落：首行缩进 2 字符（约 0.74cm）
- 参考文献内容：首行缩进（小值）

## 五、图表公式规范

### 图

- 图题格式：小五号宋体，居中
- 图题位于图下方
- 图中标注使用中文
- 数据图表要有清晰的量名称及单位
- 比例尺要清晰

### 表

- 表题格式：小五号黑体，加粗，居中，位于表上方
- 表内文字：小五号，中文宋体，西文 Times New Roman
- 表使用三线表

### 公式

- 必须使用公式编辑器处理
- 公式居中排列
- 公式序号右对齐，格式为 (1)、(2) 等
- 变量用单个字母或单个字母带上下标表示
- 上下标表示变量时用**斜体**，其他情况用**正体**

## 六、参考文献格式

### 格式要求

- 标题：四号黑体
- 内容：小五号，中文宋体 + 西文 Times New Roman
- **中英文双语**：中文文献先写中文原文，再附英文翻译，末尾加 `(in Chinese)`
- 英文文献直接引用

### 文献类型标识

| 标识 | 类型 |
|------|------|
| [J] | 期刊论文 |
| [D] | 学位论文 |
| [C] | 会议论文（文集析出） |
| [M] | 专著 |
| [P] | 专利 |
| [S] | 技术标准 |
| [R] | 科技报告 |
| [N] | 报纸析出 |
| [/OL] | 网络版 |

### 作者姓名规则

- 中文：姓名全写，三人以上用"等"
- 英文：姓氏全大写，名字首字母大写，三人以上用 `et al.`

### 参考文献示例

**期刊论文**：
```
张金国, 舒礼伟, 王隽, 等. 大功率舰艇推进轴系合理校中技术及工艺[J]. 船海工程, 2007, 36(4): 25-27
ZHANG Jinguo, SHU Liwei, WANG Juan, et al. The rational alignment technique of the propulsive shafting in the high powered warships[J]. Ship & Ocean Engineering, 2007, 36(4): 25-27 (in Chinese)
```

**专著**：
```
李万祥, 褚衍东. 工程优化设计与MATLAB实现[M]. 北京: 清华大学出版社, 2010
LI Wanxiang, ZHU Yangdong. Engineering optimal design and Matlab implementation [M]. Beijing, Tsinghua University Press, 2010 (in Chinese)
```

**学位论文**：
```
魏文儒. 基于ANSYS的空间桁架优化研究[D]. 大连: 大连理工大学, 2007
WEI Wenru. Optimized research of space truss structure based on the ANSYS[D]. Dalian, Dalian University of Technology, 2007 (in Chinese)
```

## 七、引用格式

论文末尾需附带引用格式示例（斜体），格式如下：

```
引用格式：张三，李四. 文章题目[J]. 期刊名，2021,39(1): 11-16
ZHANG San, LI Si. English title[J]. Journal Name, 2021,39(1): 11-16 (in Chinese)
```
