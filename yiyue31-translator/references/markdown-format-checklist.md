# Markdown 格式检查清单

## 检查项 (12项)

### 1. 标题层级
- 顺序：`#` → `##` → `###`，不跳级
- 标题前后有适当空行
- 标题末尾无空格

### 2. 列表缩进
- 同级列表缩进一致（2空格）
- 分隔符统一（全用 `*` 或全用 `-`）
- 嵌套列表正确缩进（每级+2空格）

### 3. 代码块
- 格式：` ```语言 ` 开头，` ``` ` 结尾
- 保留原始缩进
- 语言标识正确（markdown、bash、python等）

### 4. 数学公式
- 行内：`$公式$`
- 独立：`$$公式$$`
- 特殊字符正确转义

### 5. 表格格式
- 格式：`| 列1 | 列2 |`
- 表头：`| --- | --- |`（至少3个`-`）
- 每行首尾都有 `|`
- 单元格内 `` 需转义为 `\|`

### 6. Mermaid图表
- 格式：` ```mermaid ` 开头
- 语法正确
- 正确关闭

### 7. 换行规则
- 段落间：空1行
- 列表项间：无空行
- 标题前后：各空1行

### 8. 空行控制
- 连续空行不超过2行
- 代码块前后有空行
- 表格前后有空行

### 9. 链接格式
- 格式：`[文本](URL)`
- URL有效
- 特殊字符正确编码

### 10. 特殊字符转义
- 文本中 `\|` 而非 `|`
- `<` → `\<`，`>` → `\>`
- `*` `_` 在非格式化文本中转义

### 11. 行尾空格
- 无多余空格
- 无不可见字符

### 12. 中英文空格
- 规则：中文与英文/数字间加1空格
- 格式：`这是 English 文本`
- 例外：英文术语后紧跟 `(`中文`)`
  - ✅ `Generator (生成器)`
  - ✅ `**Planner:** 我们`
  - ❌ `Generator(生成器)`
  - ❌ `**Planner:**我们`

## 快速检查命令

```bash
# 检查粗体标题冒号空格
grep -n "\*\*.*\*\*:" file.md

# 检查中英文间无空格（需要手动审核）
grep -E "[一-龯][A-Za-z0-9]|[A-Za-z0-9][一-龯]" file.md

# 检查行尾空格
grep -n " $" file.md

# 检查连续空行（超过2行）
grep -Pn "^(\s*\n){3,}" file.md
```

## 常见问题速查

| 问题 | 错误示例 | 正确示例 |
|------|---------|---------|
| 粗体标题冒号 | `**标题:**文本` | `**标题:** 文本` |
| 中英文空格 | `这是English文本` | `这是 English 文本` |
| 列表缩进 | `* 项目1`<br>`  * 子项` | `* 项目1`<br>`  * 子项` |
| 表格格式 | `|列1|列2|` | `| 列1 | 列2 |` |
| 代码块语言 | ```` ``` ```` | ```` ```markdown ```` |
| 连续空行 | (3个及以上空行) | (最多2个空行) |

## 评分标准

- **优秀 (Pass)**: 12/12 通过
- **良好 (Minor)**: 10-11/12 通过，仅有minor问题
- **合格 (Major)**: 8-9/12 通过，有major问题需修复
- **不合格 (Fail)**: <8/12 通过，有critical问题需立即修复

## 修复优先级

1. **Critical** - 影响渲染（表格格式、标题层级）
2. **Major** - 影响可读性（中英文空格、列表缩进）
3. **Minor** - 优化改进（空行控制、行尾空格）
