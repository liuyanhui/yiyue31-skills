# Translation Corrections

Terms that LLMs commonly mistranslate in tech articles. Only include terms where the LLM would produce a wrong or inconsistent translation without guidance.

| English Term | Correct Translation | Why |
|--------------|---------------------|-----|
| agent | 智能体 | LLM defaults to "代理" |
| agentic | 智能体化的 | LLM defaults to "代理的" |
| compute | 算力 | In AI context, LLM says "计算" |
| open weight | 开放权重 | LLM says "开放重量" |
| burn rate | 烧钱率 | LLM says "燃烧率" |
| vibe coding | 氛围编程 | New slang, LLM doesn't recognize |
| triage | 分流 | LLM uses medical sense "分诊" |
| pipeline | 管线 | LLM says "管道" |
| tentpole | 核心支柱/旗舰 | LLM says "帐篷杆" |
| canonical | 权威的/唯一的 | LLM says "规范的" |
| MoE | 混合专家模型 | Abbreviation, LLM may not expand correctly |
| fast-follower | 快速跟随者 | Business term, LLM may literal-translate |
| vaporware | 雾件/概念产品 | LLM says "蒸汽软件" |
| shell out | 调用外部命令 | LLM literal-translates |
| elicitation | [KEEP]（交互式请求） | MCP-specific, LLM translates as "引出/抽取" |

## Rules

- **[KEEP]** — Do not translate, keep English
- **Chinese translation** — Use this instead of LLM's default
