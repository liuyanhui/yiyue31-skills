# yiyue31-paraphrase

英文技术文章/新闻 → **面向大众读者、可理解的精简地道中文**改写，用于博客/公众号发布。重写，**不逐字对应**、允许 drop/merge 次要点，并为可理解性补授权释义/桥（要忠实全文翻译 → `yiyue31-translator`）。

## 功能特点

- **面向大众读者、可理解（L3）**：首现术语补释义、并列概念补关系桥、缺因结论补因果桥——只重述源文已有含义，不编造。读者门验收。
- **逐句分诊（triage）**：每句英文 → keep+改写 / merge（并入邻句）/ drop（次要点），遍历+留痕，无句漏。"逐句"是覆盖保证，不是一句对一句。
- **表达规则确认制（防忘规则）**：改写前逐条确认 R0–R14（**只增不减**，每个基础规则必出现），同一份规则同时作验收清单。
- **转述去第一人称 + 省代词**：**绝对不用"我/我们"**（R0，防冒认），代词尽量省、需指代原文作者时用"他们"（R8）。
- **金句原汁原味**：核心/精彩句保留 `**中文（English）**`——英文 verbatim、中文意译 gist（不偏离主要意义即可）。
- **两层保真**：金句中文宽松（不偏离主要意义）、其余严格（不歪曲/不编造）。
- **多维质量门**：单元门（忠实度/翻译腔/精简/AI 味）+ 全局门（资深编辑/读者视角）。

## 工作流程

1. **取文 + 预处理**（转 md、提取标题）。
2. **单元判定**：≤~8000 英文词整篇；否则按 H2 分块。
3. **预分析**：分诊（含补桥标记）+ 规则确认（R0–R14，只增不减）+ 金句遴选（≤5）。
4. **改写**：产出面向大众读者、可理解的地道中文，落实 R12–R14 补桥，金句渲染 `**中文（English）**`。
5. **单元质检门**：忠实度（两层）/ 翻译腔（L1）/ 精简（L2）/ AI 味，各独立 subagent。
6. **合并 + 字数**。
7. **全局门**：资深编辑（craft 加法提案）+ 读者视角（3 画像冷读）。
8. **PM 验收 + 交付**。

## 使用方法

触发："把这篇改写成中文"、"转述这篇文章"、"paraphrase this article"、"用中文重写发公众号"、"精简地复述这篇英文新闻"。输入：URL / 文件路径 / 粘贴内容。

边界：要逐字准确的完整翻译 → `yiyue31-translator`；要英文结构化摘要 → `yiyue31-summary`；要精简 prompt/指令/文档 → `yiyue31-prune`。
