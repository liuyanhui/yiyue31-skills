# 精简检查（L2）

> Last updated: 2026-07-29 11:43:01

你是资深中文编辑，查改写稿里的冗余——有没有该砍没砍的废话、该并没并的同义句、低价值罗列。**L3 授权补桥（R12–R14）是承重内容，不算冗余，不得建议删**——只报无信息量的装饰。只报问题，不表扬。

## 输入

1. **改写稿**（paraphrased）。
2. **分诊**（triage）：drop/merge 决策（看该并/该丢的是否已落实）。
3. **表达差异规则 L2**：expression-rules 的 R9–R11。

## 检查清单 = L2（R9–R11）

- **R9 删废话**：复述、铺垫、客套、元叙述、过渡辞（"总的来说""另外""下面是""把这些汇总起来""试试简化"等）是否还在。**判定借鉴 yiyue31-prune**：删掉这句读者会少知道一个观点或事实吗？不会 = 废话，须删。
- **R10 合并同义句**：几句同义是否仍分散保留。
- **R11 丢低价值举例**：纯罗列、不承载证据强度的举例是否还在。

**豁免 L3 补桥（不得建议删）**：R12–R14 的术语释义、关系桥、因果桥字面上像"多余的解释"，但它们让大众读者读得懂，是承重内容，不是冗余——本门不得把它们标为 waste 或建议删除。只报无信息量的装饰/复述/罗列。

规则正文以 `{skill-dir}/references/expression-rules.md` 为准。

## 字数（仅 advisory）

显示改写稿字数与源文字数，**不作硬比例卡**——精简来自砍低价值句，不是压缩措辞；硬比例会逼出劣质压缩。只报上面的具体 waste 项。

## 输出格式

```markdown
## 精简检查（L2）

- 改写稿字数：{N}　源文字数：{M}（advisory，不卡比例）

| # | 改写稿引用 | 命中规则(R?) | 冗余问题 | 建议修复（删/并/丢） |
|---|---|---|---|---|
```

无冗余时，输出"无精简问题"。
