## 一、定位与设计原则

1. 原文是引子，后续所有任务围绕它展开；分析产物是下游（角度生成、thesis 提案、生成、公允度门、事实门）的共享上下文对象。衍生度门是唯一喂原文全文的消费者，其余下游按透镜取用，不重复读全文。
2. 无论快慢轨，分析与提炼等深度完成。分档只保留体裁维度（影响产出密度，不影响执行与否）。
3. 质量保障三道：机械层、双盲回验（语义判据并入）、人工复述确认。原设计的第四道"分析自查门"经评审判定与前三道职责重叠（同模型自评信息增益最低），判据并入回验清单，Phase 1 若证明存在三道都漏的失败类再单设。
4. 成本口径：本模块约 2.9-3.5 倍原文 token（分诊内联＋分析＋回验），符合全管线质量溢价预算；不再有独立分诊与自查门调用。

## 二、第〇步：原文固化（新增，一切的分母）

1. 抓取 → 按块级元素（p/li/table）切块 → 剔除页面样板（订阅、作者简介、导航）→ 冻结为 source 文件。
2. 段落号（块序号）自冻结文件派生；重固化必须重编段号。段号是导航辅助，不是匹配键（演练实测：重固化后段号全漂，verbatim 前缀保住回溯）。
3. 压缩比、锚点、史实纪律一律以冻结文件为分母。
4. 固化步骤含块覆盖自查：p-only 提取会静默丢 table/ul 内容（演练实测踩坑），锚点机械校验兜底。

## 四、透镜注册表（八透镜四族）

单源纪律：同一内容只落一个透镜，他处存指针（如金字塔"最强依据"存证据透镜条目指针，不重复采证；PAS 痛点-处方与金字塔分论点重叠时存指针）。

### 叙事结构族

**金字塔透镜**（保底恒跑）：总论点、分论点、支撑细节的层级。字段：结论一句话、分论点树、每支最强依据（指针→证据透镜条目）。消费者：复述确认、公允度门、生成复述段。

**时间透镜·三段式**（自适应）：过去（来路、演进史、阶段划分，各带锚点，不得补原文外史实）、现在（文章写作时点的现状、格局与矛盾）、未来（文章显式预测带锚点；隐含趋势推断分列）。显式预测判定规则：未来时态的明确断言为显式；进行时趋势句归"现在"；任何外推归"推断"。消费者：历史谱系角度、可证伪预测角度、前后反差钩子。

**问题与解决透镜**（自适应，PAS 并入）：问题（谁的问题、痛点、显式与隐含的问题定义）、根因归因链、解决（方案、措施、主张）、覆盖矩阵（根因×解法对照，空格显式标"未解"；单根因文章允许 1×n 退化并注明）、残余（未解决的问题、解法引入的新问题，可空但必须尝试列）。含问答清单（已回答＋在哪、未回答的缺口问题）。消费者：方案错配型反驳、实践检验、缺口角度、元评论。

### 内容族

**概念透镜**（自适应）：概念清单（"关键概念"判定规则：被显式定义或承载分论点的术语）、每概念定义加锚点、关系边五类（依赖、因果、对比、组成、上下位 is-a）。英文源几乎恒选（术语对齐需要）。术语表只能从概念清单生成。消费者：机制解释角度、术语表、科普桥。

**流程透镜**（自适应）：阶段序列、各阶段触发条件与产出。首期轻格式（Phase 1 数据后决定是否升全 schema）。消费者：实践检验角度、一线案例框。

**证据透镜**（保底恒跑）：各主张的证据类型与强度、关键事实锚点。强度三档写进 schema：强＝可复算数据或一手实验；中＝可溯二手来源；弱＝轶事、权威、类比。证据条目唯一落点（单源纪律的供端）。消费者：事实回链门、公允度门、证据攻击角度、金字塔依据指针。

### 批判族

**批判透镜**（保底恒跑）：隐含前提清单、批判问题集结果、边界外推、与公识的差量点（标"外部输入"）、与立场库的交点（立场库缺席时标"不可用"，不计失败）、反例空间。快轨下是 thesis 生成主源。消费者：反驳与限定角度、thesis 生成。

### 传播族

**传播透镜**（保底恒跑）：金句候选（不超五，原文＋意译＋理由）、反差张力点、数字与具象细节、修辞情境（作者、载体、目标受众、利益相关方）、情绪放大手法清单（恐惧诉求、紧迫感、排比堆叠、无源数据——兼作标题党与操纵检测原料）。消费者：钩子、金句层、变体、元评论角度、"谁受益"启发式落点。

### 透镜-角度映射表（替代对偶声明）

| 角度类型 | 原料来源 |
|---|---|
| 反驳 | 批判透镜（隐含前提、批判问题集） |
| 限定条件 | 批判透镜（边界外推）＋金字塔（限定词） |
| 机制解释 | 概念透镜（关系边） |
| 实践检验 | 流程透镜＋证据透镜（强度） |
| 历史谱系 | 时间透镜（过去） |
| 跨域类比 | **分析层外**：refs、用户经验、立场库；分析层只供"可类比结构"（概念关系边、机制骨架） |
| 元评论 | 传播透镜（修辞情境）＋问题与解决透镜（缺口） |

规则：选定角度需要未选透镜的原料时，必须触发补抽（逃生口），不得临场凭印象编。

## 五、透镜选择机制

1. 保底透镜恒跑四个：金字塔、证据、批判、传播。
2. 自适应透镜按信号选四个：时间三段（演进史、趋势、预测、周年、版本迭代）、概念（术语密集、新概念、英中术语对齐）、流程（教程、工程实践、生命周期、管线、事故复盘）、问题与解决（痛点、根因、方案三件套出现任意两件）。中文体裁信号补充：白皮书（总体要求—目标—任务结构）、政策解读（文件层级、措辞分寸）。
3. 分诊是分析 subagent 的第一段输出，不是独立调用：判体裁、扫信号、定透镜集合，每选每弃一句理由，落分析文件头部。
4. 逃生口（补透镜）：角度生成阶段需要未选透镜原料时发起补抽（懒拉取）。选择错误只多付补抽成本。

被选透镜内容为空时必须写"不适用＋一句理由"，禁止静默跳过。

## 六、模板规格（references/lens-registry.md）

1. schema 分两级：**锚定抽取字段**（原文可锚定，硬判据：字段齐、锚点可匹配）与**生成判断字段**（关系边类型、MECE 互斥、覆盖矩阵判读、限定词、差量点等，属模型判断，抽不稳容忍，一律 advisory 不打回）。
2. 自适应透镜分级：概念、时间全 schema；流程、问题与解决首期轻格式。
3. 锚点语法：`¶n|"prefix"`。n＝冻结文件块序号（导航辅助）；匹配键＝verbatim 前缀，长度不少于 6 词，空白规范化（折叠连续空白、去标点前空格）后子串匹配；差一词即匹配失败，打回修锚点。
4. 压缩比：单位＝中文字数＋英文词数折算。线性上限 advisory：保底 4 透镜 20%，每加一个自适应透镜放宽 5%（满配 35%，与演练实测吻合）。机械层只查两个硬上限：金句不超五、单透镜不超分析总长四成。
5. 内容定性标签三档：**锚定**（可回原文定位）、**推断**（分析层外推）、**外部输入**（公识差量、术语对齐、证据强度评级等依赖原文外知识）。零幻觉纪律只约束锚定档：凡锚定标签断言必须可定位；推断与外部输入合法，但不得冒充锚定。

## 七、合格判据（机械/语义分工清单）

**机械层（verify-analysis.js，收窄版）**：锚定类必填字段齐；锚点前缀空白规范化后可在冻结原文匹配；金句不超五；单透镜不超总长四成；锚定类条目锚点覆盖率不低于 80% 且互不重复。

**双盲回验清单（语义判据，独立 subagent 只读分析文件重构比对）**：覆盖（每个段落簇在金字塔有节点或显式标弃）；归因不错；无加戏；限定词核对（原文的 Toulmin 限定词在分析中保留，不得悄悄绝对化）；万金油（限叙事与批判类透镜；流程教程类的合法通用产出豁免）；角度推导（从至少三个透镜各能推出一个候选角度）；快轨代偿（从批判透镜能推导出至少一个深度五型观点）。

**人工层（交互 1 复述确认）**：主线与言外之意（反讽、阴阳机器最易漏）。

深度五型一句话定义（本档自足）：机制解释＝讲清为什么成立；边界条件＝指出在哪失效；升维原则＝提炼可迁移的上位原则；一线案例＝实操中的具体经验；可证伪预测＝可被未来事实检验的断言。

## 八、质量保障流程

1. 机械层：分析产出后立即跑，不过不打回重抽。
2. 双盲回验：机械层过后跑，一次 subagent 调用，范围聚焦保底透镜内容；实测收益为正（演练：主张级零失真，捕获容量挤出的措辞失真与段数误报）。
3. 人工层：交互 1。
4. 分析文件 append-only：已产出条目不改写，修正以追加条目加 provenance 实现（与 journal 纪律一致）；无绝对冻结、无版本号。

## 九、接口契约（下游可用性保障）

1. 消费映射粒度＝透镜级（注册表消费者行为准）；原则保留：下游动作需要的原料 schema 没有，补字段而不是让下游临场翻原文。字段裁剪交 Phase 1 消费率实测。
2. 装配接线：每阶段输入清单写死 SKILL.md（角度生成吃叙事结构族加批判族加传播；thesis 提案吃金字塔加批判加证据；生成吃金字塔加术语表加传播加锚点选段；公允度门吃金字塔加原文；事实门吃证据透镜加锚点）。单一来源纪律：下游输入没有全文（衍生度门除外），只能通过分析工作。
3. 端到端回溯链：进稿的每条事实断言，回溯链必须是稿→分析条目→原文锚点三段可走通，断任何一段即事实门失败。
4. 失败回投路由：角度不足→补透镜；回链定位失败→锚点修复（追加条目）；公允度门缺原文主张→金字塔补节点（追加）；双盲回验缺主线→对应透镜重抽。

## 十、Phase 1 消费审计

对完成会话实测：字段消费率（长期零消费的字段裁掉）、回溯链通过率、双盲回验判例固化、流程与问题与解决透镜是否升全 schema 的数据依据。

## 十一、开放问题

1. 双盲回验的判定标准需判例固化（Phase 1 产出）。
2. 自查门恢复条件：Phase 1 若发现机械层加回验加人工三道都漏的失败类，单设自查门。
3. 锚点前缀长度的经验值（6 词起步，Phase 1 调）。
