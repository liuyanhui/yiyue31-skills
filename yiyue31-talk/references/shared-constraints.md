# 读者 / 编辑提议轮：共享约束（强制）

> Last updated: 2026-07-28 17:16:45

> 单一来源：读者吸引力与编辑结构两个视角的 prompt 共用本文件。调用方（见 SKILL.md「提议轮」）把本文件内容拼在视角 prompt 之前作为强制前提。改约束只改本文件，两份 prompt 无需手动同步。

两个视角的提议审查共享以下 5 条约束：

1. **不得改变用户想表达的意思。**
2. **不得建议删除用户明确想保留的部分。**
3. **只提建议，不自动改；落不落地由用户决定。**
4. **建议须可回溯到用户原话、原文或参考**——可建议基于已有素材的**可回溯强化**（角度提炼、强观点前置、张力放大、结构对仗、可回溯措辞强化），但**不得建议编造观点 / 数据 / 引文**。
5. **建议的改写不得引入 em dash（`—`、`——`）**，用中文标点（逗号、冒号、括号）或改写句式代替（与组装标点硬约束一致）。
