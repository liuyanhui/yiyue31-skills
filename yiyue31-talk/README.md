# 用户心得分享 Skill

读到好文章（技术/新闻）后，快速产出**可分享的中文心得成品**。AI 不盘问、不替用户下判断，只呈现原文内容、整理用户的话；任何加值一律经用户确认（提案制）。

## 功能特点

- **采集与生成解耦（content pool）**：见 SKILL.md 核心架构。
- **重点保护**：重点作为内容项字段，生成强制落实（重点项即使被标"删"也进主轴）。
- **提案制 + 忠实护栏**：AI 加值逐条由用户确认；faithfulness 所有路线统一适用。
- **采集前配置问卷**：两段式问任务参数（采集方式/形态/读者/篇幅/参考），默认可一键开始。
- **加法门 + 减法门**：提议轮（加法，建议供确认）后跑 faithfulness + 翻译腔/可读性/AI 味（减法）。
- **断点恢复**：`progress.json` + `journal.md`，中断后精确续做，整个 `{title}/` 跨设备流转。
- **参考资料**：URL/md/txt 随时补，落盘 `refs/` 含溯源。

## 采集与生成

- **采集**：dump（分批写）/ 策展（AI 摆点、你挑你批注）/ 混合来回切；都只往内容池填 item。
- **生成**：只读内容池，按权重＋重点排结构主轴，按来源三栏标注。
- **形态**：自由结构（分享，钩子前置）/ 模板（归档，固定四块）；问卷时选一，另一种按需再出。

## 工作流程

Step 0 输入格式化 → config 问卷 → 采集（填 pool，说 done 结束，D3 缺口提示可选）→ 生成（读 pool 组装）→ 提议轮（加法，用户采纳直改生成稿）→ 质量审查（faithfulness + 三道减法）→ （可选）另一形态。

## 输出

固定中文。形态：自由结构 / 模板（引言钩子 / 正文单一论点 / 总结 / 推荐语 ≤100 社交 + ≤200 博客）。全文区分原文 / 参考[X] / 我的话。

## 使用方法

触发："提取观点"、"生成心得"、"记录我的理解"、"写收获"、"我的想法"、"我对这篇文章的看法"、"分享我的看法"、"写个推荐"；中断后续做："继续心得"、"恢复 talk"、"接着上次"、"resume talk"。

## 相关文件

- `SKILL.md`：详细工作流程（content pool schema、config 问卷、断点恢复）。
- `docs/`：设计决策与实现计划（施工期历史记录，当前真相以 SKILL.md 为准）。
- `references/`：faithfulness / reader-appeal / editor-review / shared-constraints / translationese / readability / ai-tone（ai-tone 为跨 skill 同步项）。
