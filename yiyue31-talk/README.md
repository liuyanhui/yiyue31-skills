# 用户心得分享 Skill

读到好文章（技术/新闻）后，快速产出**可分享的中文心得成品**。AI 不盘问、不替用户下判断，只呈现原文内容、整理用户的话；任何加值一律经用户确认（提案制）。

## 功能特点

- **提案制护栏 + 忠实护栏**：AI 的所有加值（角度、结构、强化、读者 / 编辑建议）都是提案，逐条由用户确认才入稿；dump 模式另加 faithfulness 检查防 AI 发挥。
- **两条路径 × 两种形态**：dump（分批写、AI 整合）/ 策展（AI 摆点、你挑你批注）；形态分享走自由结构、归档走模板，路由时选一，另一种按需再出。
- **加法门 + 减法门**：组装后先跑"读者 / 编辑提议轮"（加法，建议供确认），再跑翻译味儿 / 可读性 / AI 味儿三道减法检查。
- **中断恢复**：按已生成文件判断路径、形态与进度，支持继续 / 重开 / 跳转。

## 路径与形态

| | 适用 | 流程 |
|------|------|------|
| **dump** | 心得已成形 | 你分批写所有看法 → AI 忠实整合（不编造）→ faithfulness 检查 → 组装 |
| **策展** | 心得未成形 | AI 提原文点(≤5) → 你多选 + 打权重 → 选择性加批注 → 组装 |

形态（独立于路径）：**自由结构**（分享，钩子前置）/ **模板**（归档，固定四块）。路由时二选一，另一种按需再出。

## 工作流程

1. Step 0 输入格式化。
2. 路由：选内容路径（dump / 策展）+ 输出形态（自由 / 模板）。
3. dump：D1 分批写 → D2 AI 忠实整合 → D3 缺口提示(可选) → D4 faithfulness 检查。
   策展：C1 AI 提点(≤5) → C2 多选 + 权重 → C3 加批注（均可分批，说"done"才继续）。
4. 共用组装分享稿（按形态：自由结构先确认结构；模板按四块）。
5. 读者 / 编辑提议轮（加法，出建议供用户多选采纳）。
6. 质量审查（翻译味儿 + 可读性 + AI 味儿，并行，最多 2 轮）。
7. （可选）按需产出另一形态（re-skin + 无新增内容自查）。

## 输出文件汇总

每次任务在 `{title}/talk/` 下生成：

| 文件 | 路径 | 说明 | 检查方式 |
|------|------|------|---------|
| original-{title}.md | 共用 | 原文 | - |
| user-input-{title}.md | 共用 | **用户原话（只追加）**；首行记 route/form/input-done | - |
| integrated-draft-{title}.md | dump | AI 忠实整合初稿 | D4 faithfulness |
| review-faithfulness-{title}.md | dump | 忠实度审查报告 | - |
| article-points-{title}.md | 策展 | AI 提取的原文点(≤5 + 可补回清单) | - |
| selected-points-{title}.md | 策展 | 用户收敛 + 权重 | - |
| talk-{title}.md | 共用 | **最终分享稿（primary）** | 提议轮 + 质量审查 + 用户确认 |
| review-propose-{title}.md | 共用 | 读者 / 编辑建议报告（含采纳标记） | - |
| review-quality-{title}.md | 共用 | 质量审查报告 | - |
| talk-{title}-{form}.md | 共用 | 按需另一形态（可选） | 减法检查 + 无新增内容自查 |
| review-diff-{title}-{form}.md | 共用 | 另一形态无新增内容自查报告（可选） | - |

## 输出格式

固定中文。形态两种：**自由结构**（AI 提议结构 → 用户确认 → 钩子开篇、长短自由）/ **模板**（引言钩子先行 / 正文单一论点 / 总结 / 推荐语 ≤100 社交 + ≤200 博客）。全文区分原文 vs 我的话；数据 / 名称保持原值。

## 使用方法

触发短语："提取观点"、"生成心得"、"记录我的理解"、"写收获"、"我的想法"、"我对这篇文章的看法"、"分享我的看法"、"写个推荐"。
