# 用户心得分享 Skill

读到好文章（技术/新闻）后，快速产出**可分享的中文心得成品**。AI 不盘问、不替用户下判断，只呈现原文内容、整理用户的话。

## 功能特点

- **两条路径**：心得已成形走 dump（一次性写、AI 整合）；心得未成形走策展（AI 摆原文点、你挑、你批注）。开头一问路由，实时选。
- **不盘问**：AI 只呈现原文的"点"、只整理你说的话，不发问、不编造。
- **忠实护栏**：dump 模式严格按"原文 + 你的输入"成稿，faithfulness 检查防止 AI 发挥。
- **中文成稿 + 三道质量审查**：固定中文输出，必经翻译味儿、可读性、AI 味儿审查。
- **可分享成品**：引言 + 心得正文 + 总结 + 推荐语（≤100 / ≤200 汉字两版）。
- **中断恢复**：按已生成文件判断模式与进度，支持继续/重开/跳转。

## 两条路径

| 路径 | 适用 | 流程 |
|------|------|------|
| **dump** | 心得已成形 | 你一次性写所有看法 → AI 整合（不编造）→ faithfulness 检查 → 组装 |
| **策展** | 心得未成形 | AI 提原文点(≤10) → 你多选收敛 → 选择性加批注 → 组装 |

## 工作流程

1. Step 0 输入格式化。
2. 路由（想好走 dump / 没想好走策展）。
3. dump：D1 写 → D2 AI 整合 → D3 缺口提示(可选) → D4 faithfulness 检查。
   策展：C1 AI 提点 → C2 多选收敛 → C3 加批注。
4. 共用组装分享稿（引言 + 正文 + 总结 + 推荐语双版）。
5. 质量审查（翻译味儿 + 可读性 + AI 味儿，并行，最多 2 轮）。

## 输出文件汇总

每次任务在 `{title}/talk/` 下生成：

| 文件 | 模式 | 说明 | 检查方式 |
|------|------|------|---------|
| raw-{title}.md | 共用 | 原文 | - |
| user-dump-{title}.md | dump | 用户原始输入 | - |
| integrated-draft-{title}.md | dump | AI 整合初稿 | D4 faithfulness |
| review-faithfulness-{title}.md | dump | 忠实度审查报告 | - |
| article-points-{title}.md | 策展 | AI 提取的原文点 | - |
| selected-points-{title}.md | 策展 | 用户收敛结果 | - |
| annotations-{title}.md | 策展 | 用户批注 | - |
| talk-{title}.md | 共用 | **最终分享稿** | 质量审查 + 用户确认 |
| review-quality-{title}.md | 共用 | 质量审查报告 | - |

## 输出格式（talk-{title}.md）

固定中文，四块结构：

1. **引言**：这篇讲什么、为什么分享（1-2 句）。
2. **心得正文**：dump 为整合稿；策展为重点摘录 + 我的批注。
3. **总结**：关键启示。
4. **推荐语**：≤100 汉字（社交动态）+ ≤200 汉字（博客前言）。

全文区分原文 vs 我的话；数据/名称保持原值。

## 使用方法

触发短语："提取观点"、"生成心得"、"记录我的理解"、"写收获"、"我的想法"、"我对这篇文章的看法"、"分享我的看法"、"写个推荐"。
