## DEFER-001: 禁止模式上下文截取的多字节 UTF-8 处理

- **来源**: T-012 Criterion 4（Reviewer Round 3）
- **状态**: confirmed
- **描述**: 需求要求截取匹配位置前后各 50 个字符作为上下文，未明确多字节 UTF-8 字符的截取边界处理。按字节截取可能截断 UTF-8 字符产生乱码。
- **初步倾向**: 使用字符串按字符截取（`substring` / `slice`），Node.js 层面可正确处理多字节字符，不会截断。
- **确认结论**: TypeScript/Node.js 的 `String.prototype.slice()` 基于 UTF-16 code units 操作，覆盖绝大多数实际文本场景。对于极少数特殊情况（如 emoji ZWJ 序列），作为上下文摘要片段是可接受的。该设计方案合理，无需调整。
- **阻塞**: 否

## DEFER-004: T-005 配置合并的浅合并策略
