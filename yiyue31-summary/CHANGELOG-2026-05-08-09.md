## Key Design Decisions

1. **SKILL.md owns shared rules, templates own structure.** Accuracy, info source, word count, code handling, ordering — all moved to SKILL.md. Templates only define output sections and template-specific constraints.

2. **3-band rubric over 5-band.** Intermediate bands (7-8 and 5-6) had significant overlap. Merged into single 5-8 band. Reduces evaluation ambiguity without losing discrimination.

3. **Fidelity/Depth prioritized over readability/structure.** Analysis prompt: ED 25% > SC 15%. Polish prompt: FI 30% > RE 20%. Rationale: structural issues can be fixed downstream, but information loss cannot.

4. **Same-LLM constraint extracted to Evaluate Once.** Avoids repetition across 3 loops. Defined once in the reusable sub-workflow.

5. **Code handling is tiered.** Key snippets kept as-is; supporting code simplified. Neither "keep all" nor "simplify all" — balance between technical accuracy and summary conciseness.
